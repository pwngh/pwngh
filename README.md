# Preston Neal

I build backend libraries, workflow languages, and file tools in TypeScript, C, and SQL.
Project review: 2026-11-17.
- [economy-lab](https://github.com/pwngh/economy-lab): a double-entry credits ledger in TypeScript.
- [taskq](https://github.com/pwngh/taskq): a SQL task queue for PostgreSQL and MySQL.
- [money](https://github.com/pwngh/money): integer money arithmetic, rounding, and allocation.
- [flow](https://github.com/pwngh/flow): a typed workflow language with a C compiler and runtime.
- [unas](https://github.com/pwngh/unas): a C file server for mounted NAS shares over HTTP.
- [mysql-db](https://github.com/pwngh/mysql-db): SQL routines and schema examples (untested).
